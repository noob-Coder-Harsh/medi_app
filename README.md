# medi_app

Native app for **MediSync** — pharmacy POS, inventory, and neighbourhood storefront for Indian SME chemists.

Greenfield Flutter project. Same features and screens as the web product at `D:\code_files\nextjs\medsahayta`. One app: location → nearest shop as guest; local cart; login only at checkout; staff via long-press on the location logo.
